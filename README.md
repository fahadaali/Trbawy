# منصة المجلس التربوي

منصة داخلية مغلقة لإدارة **محاضر الاجتماعات** و**التقييمات التربوية** لثلاثة مجالس تربوية،
مبنية بالكامل على بنية Cloudflare (Workers + D1 + R2) وبواجهة عربية RTL.

> الإصدار الحالي ينفّذ المراحل حسب خطة البناء في وثيقة المتطلبات. راجع قسم **حالة البناء** أدناه.

---

## البنية التقنية

| المكوّن | التقنية |
|---|---|
| الواجهة (SPA عربية RTL) | أصول ثابتة تُقدَّم عبر Cloudflare Workers Assets |
| الخدمات الخلفية | Cloudflare Workers + [Hono](https://hono.dev) |
| قاعدة البيانات | Cloudflare D1 (SQLite) |
| تخزين الملفات | Cloudflare R2 |
| المهام المجدولة | Cron Triggers |
| البريد | خدمة خارجية (Resend / MailChannels) — تُضاف في مرحلة الإشعارات |

الكود بلا خطوة بناء معقّدة: `wrangler` يجمّع TypeScript مباشرة، والواجهة HTML/CSS/JS صرف.

---

## التشغيل محلياً

```bash
npm install

# أنشئ قاعدة D1 وضع المعرّف في wrangler.toml مكان PLACEHOLDER_DATABASE_ID
npx wrangler d1 create tarbawi-db

# أنشئ حاوية R2
npx wrangler r2 bucket create tarbawi-files

# طبّق المخطط محلياً
npm run db:init
npm run db:seed

# شغّل بيئة التطوير
npm run dev
```

عند أول طلب، تُنشأ تلقائياً المجالس الثلاثة والمستخدمون العشرة والعضويات والبنود الثابتة
وقوالب المعايير عبر `src/lib/bootstrap.ts`.

## النشر على Cloudflare

```bash
# طبّق المخطط على القاعدة البعيدة
npm run db:init:remote
npm run db:seed:remote

npm run deploy
```

الربط بـ GitHub: كل دفعة إلى الفرع الرئيسي تُنشر تلقائياً عبر تكامل Cloudflare مع المستودع.

## الحسابات الافتراضية (بيئة التجربة)

كلها بكلمة المرور الافتراضية **`1234`** مع **إلزام تغييرها عند أول دخول**.

| الدور | البريد |
|---|---|
| رئيس المجلس التربوي | `president@tarbawi.local` |
| نائب الرئيس | `vice@tarbawi.local` |
| مشرف الثانوي الأول | `sec.super@tarbawi.local` |
| مشرف المتوسط الأول | `mid.super@tarbawi.local` |
| أعضاء الفريق | `sec.m1` `sec.m2` `mid.m1` `mid.m2` `@tarbawi.local` |
| مدير النظام | `admin@tarbawi.local` |

> **ملاحظة أمنية:** كلمة المرور الافتراضية الموحّدة معتمدة كما طُلب في الوثيقة مع إلزام التغيير.
> يمكن لاحقاً التحوّل إلى كلمة عشوائية لكل مستخدم تظهر لمنشئ الحساب مرة واحدة (قرار معلّق رقم ١).

## بنية المشروع

```
migrations/        مخطط قاعدة البيانات (0001_init.sql) والبيانات الأولية
src/
  index.ts         نقطة الدخول، تركيب المسارات، تقديم الواجهة
  types.ts         الأنواع المشتركة
  permissions.ts   مصفوفة الصلاحيات (القسم ٣ من الوثيقة)
  lib/             crypto, hijri, audit, bootstrap
  middleware/      auth (الجلسات، خمول ٨ ساعات، إلزام تغيير كلمة المرور)
  routes/          auth, users, councils, audit  (+ المزيد لكل مرحلة)
public/            الواجهة العربية RTL (index.html, css, js)
```

- [x] **المرحلة ٢ — المحاضر:** الدعوة والترويسة بالترقيم التلقائي (تربوي/١٤٤٧/٠٠٣)،
  الحضور والحالات (حاضر/معتذر/غائب) والضيوف، البنود الثابتة والجديدة وجدول المتابعة،

  والإلغاء بسبب. مع فلاتر القائمة وتحرير الترويسة والبنود والحضور.
- [x] **المرحلة ٣ — المهام والقرارات:** القرار/التوصية/المهمة ككيان مستقل بترقيم تلقائي،
  المسؤولون والأولوية والاستحقاق والحالة ونسبة الإنجاز، مرفقات إثبات الإنجاز (R2)،
  آلية الإنجاز (المسؤول يضع علامة صح ← تاريخ تلقائي قابل للتعديل اليدوي مع حفظ الأصلي)،
  جدول المتابعة الذكي (يظهر المنجَز مرة واحدة ثم يختفي)، ولوحة «مهامي» وجميع البنود.
- [x] **المرحلة ٤ — التوقيع الإلكتروني والتصدير والهوية البصرية:** التوقيع من الحاضرين فقط
  مع تسجيل الوقت ورمز تحقق فريد، منع الاعتماد قبل اكتمال التوقيعات، تجاوز الرئيس بسبب مسجّل،
  صورة توقيع شخصية أو ختم افتراضي من الاسم، صفحة تحقق عامة عبر رمز QR (تُظهر رقم المحضر
  وحالته والموقّعين)، صفحة طباعة/تصدير PDF عربية RTL بالهوية البصرية (ترويسة/تذييل/شعار/علامة
  مائية/ألوان) مع رقم المحضر في كل صفحة، وإعدادات الهوية البصرية على مستوى المنصة.
- [x] **المرحلة ٥ — التقييم:** دورات التقييم (مسودة ← مفتوحة ← مغلقة ← منشورة) ينشئها الرئيس،
  إدارة المعايير والأوزان لكل فئة مع التحقق من مجموع ١٠٠٪ ونسخها داخل الدورة عند الفتح،
  مقياس ١–٥ مع «لا ينطبق» وإعادة توزيع الوزن، نماذج التقييم لكل هدف، المتوسط الحسابي المرجّح،
  النافذة التفصيلية لكل مقيِّم لكل بند، قسم «مدخلاتي» المنفصل، شريط تقدّم الإدخال لكل مقيِّم،
  وقاعدة «المُقيَّم لا يرى نتيجته». (تم التحقق من دقة الحسابات محلياً.)
- [x] **المرحلة ٦ — سجل الطلاب:** الحقول الكاملة برقم الهوية كمعرّف دائم، الإضافة/التعديل،
  النقل بين المرحلتين مع الاحتفاظ بالسجل التاريخي، الاستيراد من CSV عبر قالب قابل للتنزيل مع
  معاينة وتقرير أخطاء صفاً بصف (هوية مكررة، صف غير صالح، حقل ناقص)، التصدير، والسجل التاريخي
  (نافذة منبثقة: البيانات، الدورات ونتائجها، مخطط تطوّر، مقارنة بمتوسط الصف والمرحلة، وتنبيه التدني/التراجع).
- [x] **المرحلة ٧ — لوحات القيادة والإشعارات والتذكيرات:** جرس إشعارات داخل المنصة مع عدّاد
  غير المقروء والتعليم كمقروء، إشعارات كل الأحداث (دعوة، بانتظار توقيع، اعتماد، إسناد مهمة،
  فتح دورة، نشر نتائج)، تذكيرات مجدولة يومية عبر Cron (مهمة قبل ٣ أيام/يوم الاستحقاق/التأخر
  مع تنبيه رئيس المجلس، وإغلاق الدورة قبل ٣ أيام لمن لم يكمل) مع منع التكرار وبريد اختياري عبر
  Resend، لوحة قيادة الطلاب (عدد المقيَّمين، اكتمال الإدخال، المتوسط، توزيع الدرجات، أعلى/أدنى ١٠،
  أضعف المعايير، مقارنة بالدورة السابقة ومقارنة الثانوي بالمتوسط)، وملخص الصفحة الرئيسية الحي.
- [x] **المرحلة ٨ — سجل التدقيق والنسخ الاحتياطي:** سجل تدقيق شامل يغطي كل عملية حساسة
  (دخول، إنشاء/تعديل/اعتماد/توقيع/تجاوز/إلغاء محضر، القرارات والمهام، التقييمات، دورات التقييم،
  الطلاب، الاستيراد، الصلاحيات، الإعدادات) مع شاشة عرض بفلاتر وتفاصيل قبل/بعد وتحميل تدريجي،
  نسخة احتياطية يومية تلقائية لكل جداول قاعدة البيانات إلى R2 + إنشاء يدوي وتنزيل (لمدير النظام).
  تم التحقق من كل مرحلة محلياً عبر wrangler + D1 (المصادقة، الصلاحيات، دورة حياة المحاضر،
  التوقيع والتحقق بـ QR، حسابات التقييم، الاستيراد، التذكيرات المجدولة، والنسخ الاحتياطي).

### مراجعة الاكتمال والتنظيف

بعد اكتمال المراحل، أُجريت مراجعة تغطية شاملة مقابل الوثيقة، وأُكمِلت الميزات التالية:
- **محرر نصوص عربي RTL متكامل** لبنود المحضر (عناوين، قوائم، جداول، تظليل، صور) مع تنقية HTML
  آمنة على الخادم (قائمة سماح صارمة — تم اختبارها ضد XSS).
- **محضر تصويب/ملحق** مرتبط بالمحضر الأصلي المعتمد، مع روابط متبادلة.
- **تصدير حزمة محاضر** فترة معيّنة لمجلس في ملف واحد.
- **استيراد المعايير** من CSV بمعاينة وتقرير أخطاء.
- **بحث الأرشيف** داخل نص البنود وأسماء الحضور ونص القرارات/المهام.

وتم تنظيف الكود: لا استيرادات أو دوال أو متغيّرات غير مستخدمة (تحقق `tsc --noUnusedLocals
--noUnusedParameters`)، ولا كود ميت، وأدوات CSV والحساب المرجّح مشتركة بلا تكرار.

### تدقيق معمّق ثانٍ (مراجعة مستقلة متعددة المحاور)

أُجري تدقيق شامل ثانٍ عبر مراجعات مستقلة (تغطية المتطلبات، نظافة الكود، الصحّة والأمان)،
وعُولجت كل النتائج المؤكَّدة:

- **أمان:** إغلاق XSS مخزّن (تنقية نص البنود في كل مسارات الكتابة + شبكة أمان في المنقّي)،
  إغلاق تسريب نتائج بين المراحل في النافذة التفصيلية، إغلاق IDOR في `/file` (تضمين التواقيع
  والشعار كـ data URI داخل صفحة الطباعة وحصر `/file` بالهوية البصرية العامة)، والتحقق من أن
  كاتب المحضر عضو في المجلس.
- **صحّة:** إصلاح دالة عرض الأخطاء المفقودة، منع تعديل نص القرار بعد إقفال المحضر، إضافة قيد
  فريد لأرقام القرارات/المهام.
- **تغطية:** إضافة **لوحة قيادة المشرفين وأعضاء الفرق** (القسم ٥٫٦)، وإضافة قناة البريد
  لإشعارَي «إسناد مهمة» و«فتح دورة تقييم»، وإظهار المسؤولين في جدول قرارات المحضر.
- **تنظيف:** حذف تصديرات ميتة، توحيد منطق تقدّم المقيّمين وصلاحية الإنشاء وخرائط الحالة،
  تحويل الاستيرادات الديناميكية إلى استاتيكية، وربط واجهات لنقاط النهاية غير المربوطة.

### تحسينات تجربة تحرير المحاضر

بعد ملاحظات الاستخدام الفعلي، أُعيد تصميم تدفّق التحرير ليتم **في مكانه** بدل النوافذ المتتابعة:

- **تحرير البنود من أسفل المحضر مباشرة:** كل بند في «جدول الأعمال والبنود» صار قابلاً للتحرير في موضعه —
  تعديل العنوان بالكتابة فيه (يُحفظ عند الخروج من الحقل أو بـ Enter)، وزر «إضافة/تعديل المحتوى» يفتح
  المحرر الغني تحت البند نفسه، مع إعادة الترتيب (أسهم أو سحب وإفلات) والحذف وإضافة بند جديد من نفس المكان.
  المحتوى يُحفظ تلقائياً عند الانتقال لبند آخر أو بـ `Ctrl/⌘ + Enter`. نافذة **«تعديل البنود»** في الأعلى
  باقية كما هي للتحرير الجماعي وإعادة الترتيب دفعة واحدة. (نقاط نهاية جديدة: إضافة/تعديل/حذف بند وإعادة ترتيب.)
- **الصياغة بالذكاء الاصطناعي من مربع النص نفسه:** اختفى مربع «النقاط» المنفصل داخل النافذة —
  يكتب المستخدم نقاطه في محرر المحتوى ثم يضغط «صياغة المكتوب» فتُستبدل بنص محضر رسمي، مع زر
  «تراجع عن الصياغة» لاسترجاع ما كتبه.
- **تسجيل صوتي مباشر:** زر «تسجيل صوتي» داخل المحرر (وفي نافذة استخراج القرارات) يسجّل من الميكروفون
  مع عدّاد حي، وعند الإيقاف يُفرَّغ التسجيل نصاً ويُدرَج في المربع — مع بقاء خيار **«ملف صوتي»** لرفع تسجيل محفوظ.
- **مؤقّت الاجتماع وتعديل الوقت وحده:** لوح توقيت في ترويسة المحضر ببدء/إيقاف يلتقط **التوقيت المحلي للجهاز**
  ويعرض عدّاداً حيّاً يستمر بعد إعادة تحميل الصفحة، ويسجّل وقت النهاية والمدة عند الإيقاف. وللإدخال اليدوي
  حقل نصّي متسامح يقبل `٩:٣٠ ص` و`9:30 م` و`0930` و`9`. تعديل الترويسة صار **جزئياً**: يُرسَل الحقل المتغيّر
  وحده فلا يلزم تعبئة بقية الحقول لقبول تغيير الساعة (وتُطبَّع الأوقات على الخادم أيضاً).
- **إضافة سريعة للقرارات والمهام:** سطر واحد أسفل جدول القرارات (نوع + نص + استحقاق + Enter) بدل فتح النافذة،
  مع بقاء «إضافة بتفاصيل كاملة». وفي نافذة التفاصيل: اختصارات تاريخ الاستحقاق (اليوم/٣ أيام/أسبوع/أسبوعان)،
  و«تحديد الحاضرين» للمسؤولين، وتحميل المسؤولين الحاليين عند التعديل (كان تعديل بند يمسحهم).
- عرض الأوقات بالعربية (٩:٣٠ ص) في الواجهة وصفحة الطباعة، وحساب مدة الاجتماع تلقائياً.

## ملاحظات القرارات

1. **كلمة المرور الافتراضية `1234`** مع إلزام التغيير (كما طُلب) — يمكن التحوّل لكلمة عشوائية لاحقاً.
2. **إنشاء دورات التقييم للرئيس حصراً** (افتراض الوثيقة).
3. **تجاوز التوقيع للرئيس** متاح مع تسجيل السبب في التدقيق (افتراض الوثيقة).
4. **جهة الاعتماد الوحيدة (محسومة):** محضر المجلس التربوي يعتمده **الرئيس** فقط، ومحضر مجلس
   كل مرحلة يعتمده **مشرفها الأول** فقط — الرئيس لا يعتمد محاضر المراحل. (الرئيس يحتفظ بصلاحية
   الاطلاع والإنشاء على كل المجالس، لكن الاعتماد حصري لكل مجلس بجهته.)
